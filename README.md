# Beyond Sunlight: An Aquatic Chemosynthetic World

A project developed for the NASA Space Apps Challenge 2024 challenge **"Beyond Sunlight: An Aquatic Chemosynthetic World"**.

## Live Demo

🌐 https://bindusri2605.github.io/beyond-sunlight/

## Overview

Beyond Sunlight explores a hypothetical ocean world where life survives using chemical energy from geological activity instead of sunlight.

The project presents:

- Chemosynthetic ocean ecosystems
- Hydrothermal vents and geological activity
- Adapted alien life forms
- Food chains driven by chemical energy
- Interactive educational exploration

## Features

- Interactive web experience
- Responsive design
- Scientific concept visualization
- Educational content on chemosynthesis

## Technologies Used

- HTML
- CSS
- JavaScript

## NASA Space Apps Challenge

This project was created for the NASA Space Apps Challenge 2024 problem statement:

**"Beyond Sunlight: An Aquatic Chemosynthetic World"**

The challenge focused on imagining habitable ocean worlds where life is sustained by chemosynthesis rather than photosynthesis.

Our solution visualizes how organisms could survive in extreme underwater environments using chemical energy released from hydrothermal vents and geological activity.

The project combines scientific concepts, interactive storytelling, and web technologies to create an engaging exploration of life beyond sunlight.
